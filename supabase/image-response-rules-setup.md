# หน้าจัดการกฎตอบกลับรูปภาพ

เปิด `/chatbot/images` หลังเลือกร้านค้า ระบบแสดงกฎของร้านค้าที่เลือกเท่านั้น

รัน `image-response-rules.sql` ใน Supabase SQL Editor หลังติดตั้ง `security.sql` และระบบร้านค้าเดิมแล้ว สามารถรันซ้ำได้โดยไม่ล้างกฎที่บันทึกไว้

หน้าจัดการรองรับเพิ่ม แก้ไข ลบ ค้นหา กรองประเภท และเปิด/ปิดแต่ละกฎ พร้อมตัวอย่างข้อความและรูปภาพตอบกลับ:

- `slip`: ลูกค้าส่งรูปสลิป
- `general`: ลูกค้าส่งรูปทั่วไป
- `product`: ลูกค้าส่งรูปสินค้า

ข้อความตอบกลับหรือรูปภาพอย่างน้อยหนึ่งอย่างต้องมีอยู่ ชื่อยาวไม่เกิน 100 ตัวอักษร และข้อความยาวไม่เกิน 2,000 ตัวอักษร

เจ้าของร้านและผู้ดูแลระบบจัดการกฎได้ พนักงานดูรายการได้อย่างเดียว ฐานข้อมูลใช้ RLS ป้องกันการแก้ไขข้ามร้านและการใช้งานของสมาชิกร้านที่ถูกปิด สิทธิ์นี้ยังบังคับใช้แม้เรียก Supabase โดยตรง

รูปตอบกลับใช้ `ImagePicker` และ bucket สาธารณะ `comment-media` เดิมจาก `comment-rules.sql` รองรับ JPG/PNG/GIF ไม่เกิน 8 MB รูปแนบเป็นสื่อส่งให้ลูกค้า จึงไม่ควรแนบข้อมูลลับ การลบกฎไม่ลบไฟล์สื่อที่อาจถูกใช้งานร่วมกัน

ขอบเขตนี้เป็นการจัดการและจัดเก็บกฎ ส่วนการจำแนกภาพและเรียกกฎเหล่านี้จาก webhook ยังต้องเชื่อมเพิ่มเติม ตารางใหม่ไม่ได้เปลี่ยนการตรวจสลิปหรือการตอบแชทเดิม

ตรวจสอบด้วยฐานข้อมูลจำลอง (ไม่อ่าน `.env.local`):

```powershell
node scripts/test-image-response-rules.cjs <path-to-@electric-sql/pglite>
npx.cmd tsc --noEmit
npm.cmd run build
```
