# หน้าอัปโหลด QR บัญชีรับเงิน

แท็บ `/slips?tab=banks` ใช้ `BankQrWorkspace` แบบอัปโหลดเท่านั้น ทั้งขณะเปิดและปิด `QR_PAYMENT_DESIGNER_ENABLED` โดยไม่แสดงฟอร์มสร้างพร้อมเพย์ การตกแต่ง ประวัติ QR หรือรายการ QR หลายรูป

ก่อนใช้งานจริง ให้รัน `supabase/bank-qr-upload.sql` ใน Supabase SQL Editor หลัง `bank-accounts.sql`, `slip-bank-controls.sql` และ `bank-registry.sql` ไฟล์นี้สร้างตาราง `bank_receiving_qr`, ฟังก์ชันบันทึก และ bucket ส่วนตัว `bank-receiving-qr` สามารถรันซ้ำโดยคงข้อมูลไว้

เจ้าของร้าน/ผู้ดูแลเลือก PNG หรือ JPG (ไม่เกิน 5 เมกะไบต์) หรือลากรูปมาวาง เลือกธนาคาร กรอกเลขบัญชีและชื่อบัญชี แล้วกด “บันทึก QR รับเงิน” เซิร์ฟเวอร์ตรวจชนิดไฟล์จริง ขนาดและความละเอียด อ่าน QR และตรวจโครงสร้าง Thai QR/รหัสตรวจสอบก่อนเก็บรูป ไม่รับ QR ที่เป็นลิงก์เว็บไซต์

`GET/POST /api/bank-accounts/qr?tenantId=<UUID>` ตรวจสิทธิ์เจ้าของร้านและแพ็กเกจตามระบบเดิมก่อนอ่านหรืออัปโหลด `GET` คืนบัญชีหลักและสถานะรูปหนึ่งรูป ส่วน `&asset=image` อ่านรูปผ่าน API ที่ตรวจสิทธิ์ ไม่เปิด URL สาธารณะหรือให้ browser อ่าน storage โดยตรง

เมื่อบันทึก ฟังก์ชัน `save_bank_receiving_qr` จะเพิ่ม/เลือกบัญชีเดียวกันใน `bank_accounts`, เปิดใช้งานและตั้งเป็นบัญชีหลัก พร้อมผูกรูปในธุรกรรมเดียว `processSlip` และ Payment Pro อ่านบัญชีที่เปิดใช้งานจากตารางนี้อยู่แล้ว จึงไม่ต้องเปลี่ยนวิธีตรวจผู้รับของ SlipOK ทั้งธนาคารและเลขบัญชีจริงใช้ตรวจเทียบข้อมูลจากสลิป รูป QR ไม่ใช่หลักฐานรับเงิน และ QR พร้อมเพย์อาจไม่บอกเลขบัญชีธนาคาร จึงต้องกรอกบัญชีที่ผูกกับ QR ให้ถูกต้อง

ข้อมูลบัญชีเก่า ประวัติและรายการรับเงินไม่ถูกลบ บัญชีเดิมที่ยังเปิดใช้งานคงตรวจสลิปได้ตามเดิม ส่วนรูปหลักในหน้านี้มีได้หนึ่งรูปต่อร้าน รูปเก่าจะถูกนำออกจาก storage หลังบันทึกรูปใหม่สำเร็จ หากเปลี่ยนบัญชีต้องอัปโหลดรูปใหม่ หากแก้เพียงชื่อบัญชีสามารถใช้รูปเดิมได้

การแก้ไขพร้อมกันตรวจด้วย version และไม่บันทึกทับข้อมูลใหม่ของผู้อื่น หากผลการบันทึกไม่ชัดเจนเพราะเครือข่ายขัดข้อง ให้โหลดข้อมูลล่าสุดก่อนลองใหม่ ระบบไม่ลบรูปที่อาจบันทึกสำเร็จแล้ว

ตรวจสอบแบบออฟไลน์ ไม่เรียก SlipOK หรือส่งข้อความหาลูกค้าจริง:

```powershell
node --test scripts/test-bank-qr-upload.cjs scripts/test-bank-qr-upload-sql.cjs scripts/test-payment-codes.cjs scripts/test-payment-codes-api.cjs scripts/test-slip-single-page.cjs scripts/test-upload-security.cjs
node node_modules/typescript/bin/tsc --noEmit --allowImportingTsExtensions --incremental false
npm.cmd run build
node scripts/check-qr-designer-browser.cjs
```

ชื่อ browser script เดิมคงไว้ แต่เปลี่ยนให้ตรวจหน้าอัปโหลดจริงใน Chrome/Strict Mode: เลือกไฟล์ ลากวาง พรีวิวหนึ่งรูป ป้องกันคลิกบันทึกซ้ำ โหลดรูปกลับจากข้อมูลจำลอง และตรวจความกว้าง 375/768/1440 พิกเซล
