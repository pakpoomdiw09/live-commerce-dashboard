# Smart Follow-up แบบไม่มี Contact Policy

ติดตั้งฐานข้อมูลตามลำดับเดิมให้ครบ (`smart-follow-ups.sql`, `smart-follow-up-presend.sql`, `manual-follow-ups.sql` และตารางเหตุการณ์ข้อความจาก `broadcast-policy.sql`/`facebook-message-window.sql`) แล้วรันเพิ่มตามลำดับ:

1. `supabase/follow-up-simplified.sql`
2. `supabase/follow-up-step-settings.sql`

รันซ้ำได้ ไม่ส่งข้อความขณะรัน SQL หากติดตั้ง migration Worker รุ่นเก่าซ้ำภายหลัง ให้รันสองไฟล์นี้ซ้ำเป็นลำดับสุดท้าย

- หน้า UI ไม่มี Contact Policy/เขตเวลา/เวลาห้ามรบกวน/เพดานต่อคนหรือออเดอร์อีกต่อไป Worker และการเข้าคิวไม่ใช้ค่าดังกล่าว ตารางเก่าคงไว้เพื่อความเข้ากันได้ของ migration เก่า ไม่ลบประวัติ
- ปุ่ม **บันทึกขั้นนี้** อัปเดตเฉพาะเวลา/ข้อความขั้นที่เลือกและสวิตช์ของประเภทนั้น ไม่ส่งค่าในช่องขั้นอื่นที่ยังไม่ได้บันทึก ปุ่ม **บันทึกทั้งประเภทนี้** ใช้ยืนยันการเพิ่ม/ลบขั้นและการตั้งค่าทั้งประเภท การแก้ไขประเภทหนึ่งไม่ยกเลิกคิวของประเภทอื่น
- การแก้ตั้งค่าใช้เลข version ตรวจป้องกันการบันทึกทับจากอีกแท็บหรือผู้ใช้อื่น เวลาแต่ละขั้นยังต้องเรียงจากน้อยไปมากและอยู่ระหว่าง 1–43,200 นาที ตามโครงสร้าง Timeline เดิม
- Manual Add เลือกลูกค้าและประเภทแล้วเพิ่มได้ แม้ไม่มี policy, ออเดอร์, สินค้า หรือยังปิด Workflow อยู่ การมีคิวที่ยังไม่จบจะคืนชุดงานเดิม ไม่สร้างซ้ำหรือเติมขั้นที่ส่งไปแล้ว สินค้า/ออเดอร์ที่เลือกต้องเป็นของร้านและลูกค้านี้จริง
- รายการ Manual ใช้ข้อความกลางและให้แอดมินตรวจร่างก่อนส่งตามเดิม การรับช่วงแชท/หยุดรับข้อความยังระงับการส่ง ไม่ขวางการเพิ่มชื่อเข้าคิว
- กฎ 24 ชั่วโมงใช้เหตุการณ์ `inbound_message` ล่าสุดของลูกค้า ร้านและ Facebook Page เดียวกันใน `broadcast_messaging_events` เช่นเดียวกับ AI/Broadcast ไม่ใช้เวลาแชทสรุปซึ่งอาจอัปเดตจากข้อความออก เวลาเท่ากับ 24 ชั่วโมง ไม่มีหลักฐาน หรืออยู่ในอนาคตถือว่าส่งไม่ได้ ตรวจทั้งเตรียมงานและทันทีก่อนเรียก Messenger
- Live Mode เปิดตลอดใน Worker รุ่นนี้ ไม่ใช้ `SMART_FOLLOW_UP_SEND_ENABLED` แล้ว การส่งยังรอ Timeline/รอบ Cron และการอนุมัติ ไม่เรียกส่งเพียงเพราะกดบันทึก ไม่มีการเปลี่ยนตารางเวลา Cron
- ยกเลิกเฉพาะเพดานจำนวนครั้งของ Contact Policy สิทธิ์แพ็กเกจ เครดิตส่งข้อความ การหยุดฉุกเฉิน การไม่ส่งซ้ำ และการตรวจชำระ/ยกเลิกออเดอร์อัตโนมัติยังทำงาน

ตรวจโค้ดและ SQL โดยไม่ส่งจริง:

```
node scripts/check-smart-followup-browser.cjs
```
