# ตอบข้อมูลสินค้าผ่าน Messenger

ข้อความ `entry.messaging[].message.text` ของเพจที่ผูกกับร้าน จะตรวจรหัสสินค้าก่อนส่งต่อให้แชท/AI เช่น `FC 1`, `CF 159`, `159`, `สนใจ 09`, `เอา 1`, `รับ A1`, `จอง A1` รองรับตัวพิมพ์เล็กใหญ่ ช่องว่างหลังคำนำ และเครื่องหมาย `:`, `#`, `!` โดยเก็บเลขศูนย์นำหน้าและตัวคั่น SKU ไว้

เมื่อพบสินค้าหนึ่งรายการ จะตอบ Generic Template Card พร้อมชื่อ ราคา รายละเอียดสั้น รูปสินค้า (ถ้ามี) และปุ่ม “สั่งซื้อผ่านเซลเพจ 🛒” ลิงก์ `/s/[store-slug]?product=[product-id]&variant=[variant-id]` เปิดรายละเอียดสินค้าและเลือกตัวเลือกนั้นในหน้าร้าน ลูกค้าต้องยืนยันสั่งซื้อในเซลเพจ ระบบสอบถามใน Messenger ไม่สร้างออเดอร์หรือตัดสต็อก ส่วน CF ใต้ไลฟ์ยังใช้เส้นทางเดิม

## ติดตั้ง

1. รัน `supabase/messenger-product-lookup.sql` ใน Supabase SQL Editor หลัง `commerce-v2.sql` และ migration ตัวเลือกสินค้าที่ร้านใช้งานอยู่ ไฟล์รันซ้ำได้ ไม่แก้ข้อมูลสินค้า และให้สิทธิ์เรียก RPC เฉพาะ `service_role` ให้รันไฟล์นี้แยกสำหรับฐานข้อมูลเดิมและหลัง full setup สำหรับฐานข้อมูลใหม่
2. ตั้ง `NEXT_PUBLIC_APP_URL` เป็น URL สาธารณะของระบบ เช่น `https://shop.example` (หรือใช้ `VERCEL_PROJECT_PRODUCTION_URL` บน Vercel)
3. เปิด `NEXT_PUBLIC_SALES_PAGE_V2_ENABLED=true` และอย่าตั้ง `STOREFRONT_V2_ENABLED=false` เปิดร้านใน `commerce_stores.is_open` และเปิดการตอบอัตโนมัติของร้าน/ลูกค้า ต้องตั้ง Page Access Token ของเพจและสมัคร webhook `messages` ตามระบบ Messenger เดิม

RPC ค้น `products.code` (ชื่อคอลัมน์ SKU ในระบบนี้), `products.id`, `cf_code`/`sku` ถ้ามี และ `commerce_variants.variant_code` แบบตรงรหัสโดยไม่สนตัวพิมพ์เล็กใหญ่ ทุกเส้นทางกรอง `tenant_id` และเฉพาะร้าน/สินค้า/ตัวเลือกที่เปิดใช้งาน ไม่ตอบสินค้าที่ archived หากมี `sales_page_url` จะใช้ URL นั้นแทนเส้นทางหน้าร้านเริ่มต้น รูปใช้ `commerce_images` และสำรองด้วย `image_url`

รหัสไม่พบ รหัสซ้ำหลายรายการ และข้อความทั่วไป จะปล่อยให้แชทเดิมจัดการโดยไม่ส่งข้อความผิดพลาด หากยังไม่ได้ติดตั้ง RPC จะบันทึกคำเตือนฝั่งเซิร์ฟเวอร์แล้วปล่อยต่อแชทเดิม การตอบใช้ `deliverRichOnce` ด้วยคีย์ `product:[inbound-message-id]` จึงใช้การป้องกันส่งซ้ำ เครดิตข้อความ การหยุดบอตเมื่อแอดมินรับช่วง และหน้าต่าง Messenger 24 ชั่วโมงตามระบบเดิม
