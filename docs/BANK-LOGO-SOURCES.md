# แหล่งที่มาและสิทธิ์การใช้โลโก้ธนาคาร

ตรวจสอบวันที่ 16 ตุลาคม 2569 ติดตั้งโลโก้จริง **34 รายการ** สำหรับธนาคาร 33 แห่งและพร้อมเพย์ ส่วน **BOC และ CLICX** ใช้ไอคอนธนาคารสำรองชั่วคราว ยังไม่ได้ติดตั้งโลโก้ครบทุกธนาคาร

ไฟล์ทั้งหมดอยู่ใน `public/banks/` จึงโหลดจาก SnapBot เอง ไม่มีการพึ่ง CDN ภายนอกในหน้าจอใช้งาน บันทึกแหล่งดาวน์โหลด รุ่นต้นฉบับ สิทธิ์การใช้ ผู้สร้าง และ SHA-256 ของแต่ละไฟล์ไว้ใน [manifest.json](../public/banks/manifest.json) พร้อม [เครดิตและข้อกำหนด](../public/banks/ATTRIBUTION.md)

## แหล่งที่ติดตั้ง

- โลโก้สีขาว 25 ไฟล์จาก [Omise banks-logo](https://github.com/omise/banks-logo/tree/2d813bc9193fd3ebd8e2c94d7f60a8a25ba956b2) ภายใต้ MIT ปักหมุด commit `2d813bc9193fd3ebd8e2c94d7f60a8a25ba956b2` เก็บ LICENSE ฉบับเต็มและประกาศเครื่องหมายการค้าจากผู้จัดทำไว้ครบ ไฟล์ไม่ถูกแก้ไข
- KKP, ไทยเครดิต, SME, EXIM, RHB, IOB, SMTB และพร้อมเพย์ จากไฟล์ Wikimedia Commons ที่ระบุ PD-textlogo พร้อมแหล่งธนาคารหรือผู้ให้บริการต้นฉบับ แสดงรายละเอียดและ revision ของแต่ละไฟล์ในเครดิต ไม่ใช้โลโก้เก่า Kiatnakin แทน KKP
- OCBC จากไฟล์ Commons รุ่นเครื่องหมายปี 2023 ภายใต้ CC BY-SA 3.0 เก็บเครดิต ผู้เผยแพร่ รุ่นไฟล์ และ legal code ฉบับเต็ม ใช้ไฟล์เดิมโดยไม่แก้ไข

โลโก้เป็นเครื่องหมายการค้าของเจ้าของแต่ละราย สิทธิ์ด้านลิขสิทธิ์เหล่านี้ไม่ได้โอนสิทธิ์เครื่องหมายการค้า และไม่ได้หมายความว่าธนาคารหรือผู้จัดทำไฟล์รับรอง SnapBot

## รายการที่ยังขาด

| รหัส | ธนาคาร | เหตุผลและการแสดงผล |
| --- | --- | --- |
| BOC | ธนาคารแห่งประเทศจีน (ไทย) | ยังไม่พบไฟล์ปัจจุบันที่ดาวน์โหลดและยืนยันสิทธิ์เผยแพร่ต่อได้ ไฟล์ Commons `Bank_of_China_symbol.svg` ที่พบในผลค้นหาเปิดไม่ได้และมีประวัติพิจารณาลบ จึงไม่ติดตั้ง ใช้ไอคอนธนาคารสำรอง |
| CLICX | ธนาคารคลิกซ์ | [ข้อกำหนดเว็บไซต์ทางการ](https://www.clicxbank.com/th/personal/website-terms-of-use) กำหนดให้ขออนุญาตเป็นลายลักษณ์อักษรก่อนคัดลอกหรือเผยแพร่ ยังไม่พบไฟล์ที่ให้สิทธิ์แยก ใช้ไอคอนธนาคารสำรอง |

ทั้งสองรายการยังค้นหาและเลือกธนาคารได้ตามสถานะที่ Registry กำหนด ไม่มีการนำโลโก้ธนาคารอื่นมาใช้แทน ไม่ดาวน์โหลดโลโก้จากแหล่งที่อนุญาตเฉพาะการใช้ส่วนตัว และไม่ใช้ไฟล์จากแพ็กเกจที่ไม่มีหลักฐานสิทธิ์ชัดเจน

## การตรวจภาพและความถูกต้อง

เรนเดอร์และเปิดดูไฟล์ทั้งหมดเป็นภาพรวม ตรวจชื่อและสัญลักษณ์ให้ตรงกับธนาคาร ไม่ใช้ TMB/ธนชาต/RBS ที่เลิกใช้แล้ว โลโก้ TTB เป็นคำว่า `ttb` ปัจจุบัน ไฟล์จาก Omise เป็นสัญลักษณ์สีขาวและต้องแสดงบนพื้นสีธนาคาร ส่วนไฟล์ Commons เป็นโลโก้สีและแสดงบนพื้นขาว ไม่เปลี่ยนสีหรือตัดรูปให้ผิดสัดส่วน

เปรียบเทียบ RHB และ IOB กับภาพส่วนหัวเว็บไซต์ทางการปัจจุบัน และเปรียบเทียบสัญลักษณ์ SMTB กับ [เว็บไซต์ธนาคารในประเทศไทย](https://www.smtb.jp/smtbthai/) โดยตรง ไฟล์ SMTB ปรับเฉพาะขอบเขตภาพ SVG ให้แสดงสัญลักษณ์สี่สีเดิมและซ่อนชื่อภาษาญี่ปุ่นของบริษัทแม่ ไม่มีการแก้เส้นหรือสี

ชื่อไฟล์และรหัสในแหล่งโลโก้ไม่ได้ใช้เป็นแหล่งรหัสตรวจสลิป โดยเฉพาะ `ttb` ใน JSON ของ Omise ระบุเลข `076` ซึ่งไม่ได้นำมาใช้ใน SnapBot รหัสตรวจสลิปใช้ Registry ของโปรเจกต์ที่ตรวจแยกกับระบบเดิม

การตรวจอัตโนมัติอ่านไฟล์จริง ตรวจ SHA-256 เทียบ manifest เรนเดอร์ภาพด้วย Sharp ตรวจว่าไม่ว่าง และตรวจ SVG ว่าไม่มี script, event handler, foreignObject, entity หรือทรัพยากรภายนอก การทดสอบใน Chrome ตรวจการโหลดภาพจริงใน component พร้อมทดสอบไอคอนสำรองเมื่อรูปโหลดไม่ได้ ดูผล Build และการทดสอบประกอบในรายงานงานนี้

## การเพิ่มหรืออัปเดตภายหลัง

1. ตรวจธนาคารและรหัสกับแหล่งทางการก่อนเลือกโลโก้ ห้ามผูกไฟล์จากชื่อย่ออย่างเดียว
2. บันทึกหลักฐานสิทธิ์เผยแพร่ต่อ แหล่งต้นฉบับ รุ่นไฟล์ และข้อกำหนดเครื่องหมายการค้า
3. เก็บไฟล์ใน `public/banks/` อัปเดต manifest พร้อม SHA-256 และเครดิต หากปรับภาพให้ระบุสิ่งที่เปลี่ยน
4. อัปเดต `logoPath`/พื้นหลังใน Registry ทดสอบภาพจริงบน dropdown ช่องเลือก และการ์ดบัญชี แล้วรันชุดตรวจโลโก้และ Build อีกครั้ง

ไม่ต้องรัน SQL migration เพื่อใช้โลโก้ ไม่มีการแก้ API key ข้อมูลบัญชีที่มีอยู่ หรือข้อมูลการชำระเงินจริง
