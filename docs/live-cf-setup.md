# ตั้งค่าระบบดูดออเดอร์ไลฟ์สด

หน้า `/live-cf` รับลิงก์วิดีโอ Facebook แบบเต็ม เช่น `/ชื่อเพจ/videos/123...`, `/watch/?v=123...`, `/watch/live/?v=123...` และ `/video.php?v=123...` เมื่อวางลิงก์หรือออกจากช่องกรอก ระบบจะเปลี่ยนเป็นรหัสให้ทันที ยังรองรับรหัสตัวเลขและ `เพจ_โพสต์` เดิม การเว้นว่างหมายถึงรับทุกไลฟ์ของเพจ ลิงก์ย่อ `fb.watch` และลิงก์แชร์ที่ไม่มีรหัสตัวเลขจะให้คัดลอกลิงก์วิดีโอแบบเต็ม ไม่เดารหัสจากข้อความในลิงก์

กด “เพิ่มสินค้าใหม่เข้าเซลล์เพจ” ข้างช่องเลือกสินค้าเพื่อกรอกชื่อ ราคา สต็อก และรหัส CF บันทึกสำเร็จจะเลือกสินค้านั้นทันที เติมรหัสจองและแสดงราคา/สต็อกในสรุปโดยไม่โหลดหน้าใหม่ สามารถเพิ่มรูปภาพภายหลังที่หน้าร้านค้า กล่องสรุปจะแสดงรูปของสินค้าที่มีรูปอยู่แล้ว

## ไฟล์ที่เกี่ยวข้อง

| ไฟล์                                       | หน้าที่                                                                           |
| ------------------------------------------ | --------------------------------------------------------------------------------- |
| `components/live-cf/LiveCfSetup.tsx`       | หน้า Tailwind, รายการสินค้าที่เพิ่มระหว่างใช้งาน, การเลือกสินค้าและสรุปการตั้งค่า |
| `components/live-cf/QuickProductModal.tsx` | หน้าต่างเพิ่มสินค้า การตรวจฟอร์ม สถานะบันทึก ข้อผิดพลาด และป้องกันกดส่งซ้ำ        |
| `lib/features/commerce/live-cf-setup.ts`   | อ่านรหัสจากลิงก์ ตรวจข้อมูลสินค้า และแปลงคำแทนข้อมูลภาษาไทยสำหรับข้อความตอบกลับ   |
| `lib/features/comments/live-products.ts`   | โหลดสินค้าของร้านพร้อมที่อยู่เซลเพจ รวมกรณีร้านยังไม่มีสินค้า                     |
| `app/(dashboard)/live-cf/page.tsx`         | ส่งข้อมูลร้านและที่อยู่เซลเพจให้หน้าตั้งค่า                                       |
| `app/api/live-cf/setup/route.ts`           | ตรวจลิงก์หรือรหัสซ้ำฝั่งเซิร์ฟเวอร์ก่อนบันทึกกฎ                                   |

การเพิ่มสินค้าใช้ `POST /api/commerce` เดิมด้วย `action: product` ซึ่งตรวจเจ้าของร้าน ต้นทางคำขอ ข้อมูลสินค้า จำนวนรายการตามแพ็กเกจ และรหัสซ้ำ ก่อนเรียก `commerce_save_product` ให้ INSERT ลง `products` ใน transaction เดียว ไม่ใช้ service key ใน browser

รหัส CF จากฟอร์มบันทึกลง `products.code` ซึ่งเป็นคอลัมน์รหัสสินค้าจริงของโปรเจกต์นี้ ตั้ง `is_active: true` และใช้ค่าเริ่มต้น `commerce_archived: false` เพื่อให้สินค้าแสดงในเซลเพจโดยอัตโนมัติเมื่อเปิดหน้าร้านและมีส่วนรายการสินค้าอยู่แล้ว ไม่เปิดหน้าร้านที่ปิดอยู่แทนผู้ใช้ ต้องเปิดระบบร้านค้าและจัดการสินค้าเดิม (`NEXT_PUBLIC_SALES_PAGE_V2_ENABLED=true` และไม่ตั้ง `PRODUCT_MANAGER_V2_ENABLED=false`)

ข้อความบนหน้าจอใช้ `{ชื่อสินค้า}`, `{ราคา}`, `{ตัวเลือกสินค้า}`, `{ยอดชำระ}` และ `{ลิงก์ชำระเงิน}` โดยแปลงกลับเป็นคำแทนข้อมูลภาษาอังกฤษเดิมก่อนบันทึก จึงยังส่งข้อความผ่านระบบเดิมได้และเปิดแก้ไขข้อความเก่าได้

## ตรวจสอบ

```powershell
npx.cmd tsc --noEmit
npm.cmd test
node scripts/check-live-cf-setup-browser.cjs
```

ชุดทดสอบ browser ใช้ Chrome บน Windows รันหน้า React จริงพร้อม Tailwind ที่สร้างจากโค้ดล่าสุด ทดสอบ URL, หน้าต่างเพิ่มสินค้า, การรักษาข้อมูลเมื่อบันทึกไม่ผ่าน, ป้องกันกดซ้ำ, การเลือกสินค้าทันที และหน้าจอ 375/768/1440 พิกเซล ภาพตรวจสอบอยู่ใน `.tmp/live-cf-ui/` การทดสอบใช้ API จำลองและฐาน PGlite ไม่สร้างสินค้าหรือส่งข้อความไปยังร้านจริง
